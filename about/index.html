About

I'm Martin Ndung'u — a software engineer based in Nairobi, Kenya. I care about backend systems, distributed design, and writing code that's still readable six months later.

What I do

Day-to-day, I work on production backend systems — mostly Java and Spring Boot, with TypeScript and Node.js along the way. I like the slightly unglamorous parts of the job: API contracts, queries that don't fall over, retry logic, the boring middle of the system.

What I'm into right now

Rust.I'm slowly working through the language by building small CLI tools and HTTP services with Axum. If you're doing the same and want a thinking partner, I'm open to collaboration.

Long-term, I'm interested in distributed systems patterns, event-driven design, and the difference between systems that look correct and systems that are correct.

Why I write here

Mostly because writing forces me to actually understand the thing. The articles on this site are notes from working through real problems — not finished, not authoritative, but hopefully useful to someone two steps behind me.
